# Real Estate Sales SaaS Platform

Production-oriented monorepo implementing:

- **Frontend:** React + Next.js (App Router, TypeScript)
- **Backend:** Node.js + Express (JWT auth, RBAC, pricing engine)

## Features

- Real estate project catalog for sales teams
- Four pricing modes:
  - PLAN SIMPLE
  - PLAN PERSONALIZADO
  - CUOTAS EXTRAORDINARIAS
  - CALCULADORA
- Dynamic payment scenario generation
- Scenario persistence and retrieval
- Basic analytics for mode usage
- Role-based access for admin and rep
